# Unit 1 — Important Questions
### Computational Thinking & Algorithmic Logic

---

## A. Short Answer Questions

1. Define an algorithm. List its five characteristics.
2. What is computational thinking? Name its four pillars.
3. Differentiate between a compiler and an interpreter, with one example of each.
4. What are the three building blocks of logic? Name them.
5. Define pseudocode. How is it different from an algorithm written in plain English?
6. What is a flowchart? List any four flowchart symbols and what each represents.
7. Define tracing/dry run and state why it is done before coding.
8. Differentiate between a syntax error and a logic error, with an example of each.
9. What is type casting? Differentiate between implicit and explicit type casting.
10. What is the difference between the `/` and `//` operators in Python? Give an example.
11. Why is indentation important in Python? What error occurs if it is inconsistent?
12. Differentiate between the `input()` and `print()` functions.

---

## B. Long Answer / Descriptive Questions

1. Explain computational thinking and its four pillars (decomposition, pattern recognition, abstraction, algorithm design) with a suitable example for each.
2. Explain the three building blocks of logic — sequence, selection, and iteration — with an example of each, and explain how every program is built by combining them.
3. Explain the IPO (Input-Process-Output) model, and use it to analyse the problem: *"find the average of N numbers entered by the user."*
4. What are the characteristics of a good algorithm? Explain each one with reference to a sample algorithm of your choice.
5. Draw a flowchart and write a step-by-step algorithm to find the largest of three numbers.
6. Write pseudocode and draw a flowchart to check whether a given number is prime.
7. Explain Python's basic data types with examples, and show how the `type()` function can be used to verify each one.
8. Explain arithmetic, relational and logical operators in Python with suitable examples for each category, and state Python's operator precedence order (at least 4 levels).
9. Explain the concept of variables in Python and the rules for naming them, with examples of valid and invalid variable names.
10. Trace the following algorithm step by step for N = 5, showing a trace table:
    *"set sum = 0, i = 1; while i ≤ N: sum = sum + i, i = i + 1; print sum."*

---

## C. Programming / Practical Questions

1. Write a Python program to find the largest of three numbers entered by the user.
2. Write a Python program to check whether a given number is prime.
3. Write a Python program to calculate simple interest given principal, rate, and time.
4. Write a Python program to find the area and circumference of a circle given its radius, formatted to 2 decimal places using an f-string.
5. Write a Python program to swap the values of two variables (a) using a temporary variable and (b) without using a temporary variable.
6. Write a Python program to convert a temperature from Celsius to Fahrenheit and vice versa.
7. Write a Python program to find the factorial of a number using a loop (iteratively), after first drawing its flowchart and writing its pseudocode.

---

*Tip: For Unit 1, be ready to produce an algorithm, its flowchart, AND a trace table for the same problem — this combination is asked very frequently.*
