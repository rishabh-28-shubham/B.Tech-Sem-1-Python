# Unit 2 — Important Questions
### Python Control Flow, Functions & Modules

---

## A. Short Answer Questions

1. Differentiate between `if-else` and `if-elif-else`, with a suitable example.
2. What is the difference between a `for` loop and a `while` loop? When would you use each?
3. Differentiate between `break`, `continue` and `pass`, with one example each.
4. What is the difference between local scope and global scope? What does the `global` keyword do?
5. Differentiate between `print()` and `return` with a short example.
6. What is a lambda function? Give an example and state one typical use case.
7. Define recursion. What is meant by a "base case" and why is it essential?
8. Differentiate between recursion and iteration.
9. What is the difference between `import module` and `from module import *`?
10. What is `pip` used for? Give the command to install a package named `numpy`.

---

## B. Long Answer / Descriptive Questions

1. Explain `if`, `if-else`, and `if-elif-else` statements with the syntax and a suitable example program for each.
2. Explain the `for` loop and `while` loop in Python with their syntax and examples. Discuss when one should be preferred over the other.
3. Explain the `break`, `continue` and `pass` statements with example programs that clearly illustrate the difference in their effect on a loop.
4. Explain functions in Python: defining a function with `def`, calling it, positional/default/keyword parameters, and returning values, with a complete example.
5. Explain variable scope in Python (local vs global) with a program, including a case where the `global` keyword is required to modify a global variable from inside a function.
6. What is recursion? Explain with the factorial function as an example, including a step-by-step trace of `factorial(5)`.
7. Compare recursion and iteration in terms of memory usage, readability, and typical problems each is suited to.
8. Explain the different forms of the `import` statement in Python with examples of each. What is `pip`, and how does it differ from the `import` statement?

---

## C. Programming / Practical Questions

1. Write a Python program to check whether a number is positive, negative, or zero using `if-elif-else`.
2. Write a Python program to print the multiplication table of a number entered by the user, using a `for` loop.
3. Write a Python program to find the sum of digits of a number using a `while` loop.
4. Write a Python program using nested loops to print a number/star pattern (e.g. a right-angled triangle of stars).
5. Write a Python program to find the factorial of a number using recursion, and using a loop; compare the two versions.
6. Write a Python program to generate the first N terms of the Fibonacci series using recursion.
7. Write a Python function `is_prime(n)` that returns True/False, and use it to print all prime numbers between 1 and 50.
8. Write a Python program that uses a lambda function together with `filter()` or `sorted()` to process a list (e.g. extract even numbers, or sort a list of tuples by the second element).
9. Write a Python program that demonstrates the use of any two standard library modules (e.g. `math` and `random`).

---

*Tip: For every loop/recursion question, be ready to draw a trace table — this is one of the most commonly asked question types in Unit 2.*
