# Pre-DSA GeeksforGeeks Question Bank (Python Core)

Problems from the GeeksforGeeks Practice portal that you can solve with core Python only: variables, operators, conditionals, loops, lists, tuples, strings, dictionaries, sets, and functions/recursion. GfG problems are identified by title rather than number, so search each title on the GfG Practice page. The difficulty tag (School / Basic / Easy / Medium) is shown in brackets.
